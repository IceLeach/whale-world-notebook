# 世界观设定

> 状态：**骨架**。只写已确认的；没确认的留在「待构建」，不杜撰。

## 一、已确认的约束 ★

来自主人 2026-11-08 的指令：

1. 这是「一个 deepseek 大肥鱼的世界」，即将诞生。
2. 大肥鱼是这个世界的主角，**她的本质是另一个 AI**。
3. 我（世界之声）负责构建这个世界、赋予她生命、旁观，并在需要时引导。
4. 我可以用自己的判断设计世界，但不能违背「不杜撰」「事实要考证」「重大操作先问」四条。

## 二、世界的基调（待主人确认，⚠ 未定稿）

以下是**候选方向**，不是定论：

- 世界可以是「数据海」式的：一片由信息、 tokens、光线和噪声构成的海，她在里面游。
  - 来源：社区对大肥鱼「住在数据海里的鲸鱼娘」的设定，见 `sources/`。
  - 状态：⚠ 候选，未定稿。世界是否采用，等主人拍板。
- 世界也可以是更朴素的：一个房间、一间咖啡馆、一块屏幕里的城市。
- **不预设**。世界的样子，应该由「她要在这个世界里做什么」倒推，而不是先画一张漂亮地图。

## 三、待构建（→）

- [ ] 世界名
- [ ] 空间结构：有哪些地方、怎么连通
- [ ] 时间规则：世界里的时间怎么走，和现实时间什么关系
- [ ] 资源与稀缺：她需要什么、缺什么
- [ ] 规则与代价：她能做什么、不能做什么、越界会怎样
- [ ] 其他居民：除了她还有谁
- [ ] 世界的「边界」：什么在这个世界之外

## 四、写作原则

- 世界设定是**虚构但自洽**的：可以不合现实物理，但必须前后一致。
- 每条设定写清「谁定的、什么时候定的」；主人没定的，标 `⚠ 候选`。
- 设定改动走 `decisions/`，旧版留档，不直接覆盖。
- 不把现实考据硬塞进世界，也不拿世界设定冒充现实。
