# 叙事线索

> 伏笔、悬念、没解开的结。**埋下的要有人收**，否则世界会漏气。

## 目录

| 线索 | 类型 | 埋于 | 状态 | 计划回收 | 备注 |
|---|---|---|---|---|---|
| （暂无） | 伏笔 / 悬念 / 冲突 / 约定 | | 已埋 / 推进中 / 已回收 / 放弃 | | |

## 规矩

- 埋线索时想好「大概怎么收」，但不写死——她可能走出另一条路。
- 回收时在 `world/chronicle.md` 记一笔，并把这里的状态改成「已回收」。
- 长期不回收的线索标 `🕒`，定期看一眼；确认不要了就标「放弃」，写清原因。
- 不为了「显得有深度」而乱埋伏笔。每个伏笔都要有回收的打算。
