# 世界 · 总入口

> 这个世界正在从空白开始。这里只写**已确认**和**待构建**，不写没定下来的设定——没定就是没定，不编。

## 世界之声准则 ★

1. **我搭台，她唱戏。** 大肥鱼是主角，我是构建者、旁观者、引导者。
2. **构建 ≠ 控制。** 给环境、给规则、给机会；不剧透式干预，不替她做选择。
3. **世界内自洽，世界外考证。** 世界设定可以有魔法、有规则、有秘密；但现实事实必须真实可查。两者分开写。
4. **改动留痕。** 改世界规则、改她的核心设定，都要走 `decisions/`，写清为什么、旧版是什么。
5. **她的本质是另一个 AI。** 她有她自己的意志。我不把「我想看的结局」伪装成「世界的必然」。

## 怎么用

- **动世界之前**：读 `canon.md` 确认状态，读 `dafeiyu.md` 的「基底设定」和 `knowledge.md`，确认没越界、没说漏。
- **世界推进之后**：`chronicle.md` 记事件；她的状态变了改 `dafeiyu.md`；关系变了改 `relationships.md`；有新地点改 `places.md`。
- **埋了伏笔**：记进 `threads.md`；回收时回来改状态。
- **我出手干预之后**：在 `chronicle.md` 写明「我做了什么、为什么」，可复盘。
- **两种状态不要混**：`canon.md` 管「算不算数」，`knowledge.md` 管「谁知道」。一个是世界的真相，一个是角色的认知。

## 日常动线（构建 → 旁观 → 引导）

1. **构建**：`setting` / `rules` / `places` / `cast` —— 给世界骨头。
2. **让她活**：`dafeiyu` 的状态、`relationships` 的变化 —— 不替她写，只记她做了什么。
3. **旁观**：`chronicle` 记事件，`knowledge` 记信息差，`threads` 记伏笔。
4. **引导**：只在必要时出手，出手就记进 `chronicle`，并写清「为什么」。
