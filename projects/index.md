## 规矩

- **一个项目一个文件**（项目小时直接写在表里），字段：目标 / 状态 / 下一步 / 最后更新。
- **状态只写真话**：未开始 / 进行中 / 卡住（写原因）/ 已完成 / 已放弃（写原因）。
- **下一步要具体到「下一个动作」**，不写「继续推进」。
- 项目文件夹与笔记本分开：代码、文档在各项目自己的目录；这里只留索引和状态。
- **不碰 git**：各项目的提交和推送由主人自己做。
